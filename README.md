# Système de Gestion de Transactions et Détection de Fraude 
Application web full-stack permettant la gestion des utilisateurs, le suivi de transactions financières et l'analyse de données via un module python.

## Stack technique
- Frontend: HTML5,CSS
- Backend: PHP, python('app.py')
- Base de données: MySQL

## Installation en local
Placer ce dossier dans le répertoire 'htdocs' de XAMPP.
Créer une base de données nommée 'bank'dans phpMyAdmin.
Copier 'db.example.php' vers 'db.php'et configurer les accès locaux
Lancer Apache et MySQL, puis ouvrir 'http://localhost/BANK/Main%20Page.html'
